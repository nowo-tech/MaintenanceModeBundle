# Symfony 8 Demo — Maintenance Mode Bundle

FrankenPHP demo: HTTP 503 maintenance + Twig panel at `/_maintenance`.

## Usage

```bash
make up
```

Open http://localhost:8055

- Panel password: `maintenance`
- Excluded health check: `/health`
